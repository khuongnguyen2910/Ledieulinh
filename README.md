# Lê Diệu Linh, landing page

Trang giới thiệu chị Lê Diệu Linh, VIP Master Pharmesthetic Việt Nam và Mentor Master Team Pharmeshouse.

## Cấu trúc

- `index.html`: toàn bộ nội dung và giao diện
- `images/`: ảnh dùng trên trang (định dạng WebP)
- `favicon.svg`: biểu tượng trên tab trình duyệt

## Cập nhật

Sửa file rồi đẩy lên nhánh `main`, Vercel sẽ tự triển khai lại.

Thay ảnh: giữ nguyên tên file trong `images/` và ghi đè bằng ảnh mới.

## Trước khi công khai

Trang đang chặn công cụ tìm kiếm. Khi chị Linh duyệt xong, xóa dòng
`<meta name="robots" content="noindex, nofollow">` trong `index.html`
và xóa dòng "Bản demo nội dung, chờ chủ trang duyệt." ở chân trang.
